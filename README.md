
# Quiz Game in C

A simple command-line quiz game developed using the C programming language.

## About the Project

This project is a multiple-choice quiz game where the user answers questions and receives a final score.

The game randomly selects questions during each round and checks whether the user's answers are correct.

## Features

- Multiple-choice questions
- Random question selection
- Answer validation
- Score calculation
- Displays the correct answer for incorrect responses
- Simple command-line interface

## Technologies Used

- C Programming
- Structures
- Arrays
- Functions
- Strings
- Random Number Generation

## How It Works

1. The program displays a welcome message.
2. A question is randomly selected.
3. Four answer options are displayed.
4. The user enters an answer from 1 to 4.
5. The program checks the answer.
6. The score is updated if the answer is correct.
7. After all questions, the final score is displayed.
